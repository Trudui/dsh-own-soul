# dsh-own-soul ·「自己」

**给 AI 一套自己的记忆和性格：纯规则、不调模型、不联网、不花 token。**

装一次就有三样东西：**人设**（地基）、**成长**（会变）、**记忆**（会忘）。数据全在本地一个目录里，拷走就走。

## 卖点：四个「别人不做」的

| 别人通常怎么做 | 这里怎么做 | 为什么值钱 |
| --- | --- | --- |
| 人格/记忆插件一注入就是几千字，聊越久塞越多 | **硬预算装填**：每轮 1200 字、五块按比例切，塞满就停 | 它自己这块的边际成本是常数——聊一年也还是 1200 字。**注意：这只管它自己注入的那个块，历史消息照样会涨** |
| 记忆只增不减，越用越慢越乱 | **双轴强度衰减**（时间 × 命中），低于阈值不再注入、降到 0.1 才退场，还能捞回来 | 会忘，但忘得可解释；不是"删了"而是"淡了" |
| 记错了照样理直气壮 | **说法打架先冻住**，新说法挂起等你裁决；改动留 5 版历史；注入里主动声明「有 N 条我拿不准」 | 这是能被签字的那种记忆，不是"AI 说得挺像" |
| 人格靠模型自己给自己打补丁，一轮一轮漂 | **纯规则蒸馏**：每轮记流水，每晚 23 点写日记、抽候选，跨两天才转正 | 不烧 token、不联网，行为可复现、能解释是哪句话让它变的 |

再加三条细节：**换会话不断片**（接续卡温启动）、**不污染全局**（按对话勾选启用）、**人格可导入导出**（三段 JSON，换 profile 也能带走）。

### 先说清楚它**不**做什么

省 token 这件事很容易被吹过头，这里划死三条：

- **它不是压缩器**，不压缩历史。历史越来越长要靠压缩插件（比如 billion-context 的折叠线），那是另一个人的活。
- **它不瘦身工具表**。工具表是每请求的固定开销（本机实测 64 个工具 ≈ 12.9K token），跟聊多久无关，砍插件才有用。
- **它自己每轮还往里加约 1200 字**（≈800 token）。它带来的是"记忆和性格"，不是"更小的上下文"。

那它跟省 token 的关系是什么？**让"短会话"变得可行。** 一个话题开一个新会话，第一轮靠接续卡 + 检索出来的记忆接上，不用把三个月的历史拖进来——这才是它间接省下来的部分。

（真数字：本机这个对话最近一次请求约 282K token，其中新增 1,029、命中缓存 281,344；工具表 12.9K；own-soul 注入 800。占比 0.3%。）

## 一轮对话里它到底做了什么

你发一句，到它回答完，中间只有一次「插件插手的时刻」——组装系统提示的时候。**纯本地，零 token，零网络。**

```
你按下发送
   │
   ├─▶ DSH 送出 user/message 事件
   │      └─ 插件只是把它存进内存（谁说了什么、seq 多少），不写盘
   │
   ├─▶ 组装系统提示 system-prompt/assemble   ← 插件唯一插手的时刻（纯本地）
   │      ① 回填流水：从会话事件流里把「一问一答」补进 journal/今天.jsonl
   │         去重键 = 会话 id + seq（实时事件漏了也能补上）
   │      ② 可能写接续卡：问答对 ≥ 24 且距上次 > 30 分钟 → 一张 800 字交接卡
   │      ③ 注入两段：
   │         dsh-own-soul:persona  ← 人设三段，永远排最前
   │         dsh-own-soul:grown    ← <自我记忆> 五块硬预算
   │                                交接 24% / 特质 22% / 记得的事 28%
   │                                最近 14% / 突然想起来 12%，共 1200 字封顶
   │      （前提：这个对话在你勾选的白名单里；子代理一律跳过）
   │
   ├─▶ 发给模型：系统提示（含上面两段）+ 历史（超 30% 折叠线由 billion-context 先压）
   │              + 工具表 + 你这条          ← 这一步才花钱
   │
   ├─▶ 它回答（读文件、跑命令都发生在这里）
   │      └─ assistant/message：插件只暂存文本，不落盘
   │
   └─▶ 这一轮结束 turn/end
          把「你那句 + 它最后那段」成对写进 journal/2026-10-29.jsonl
          顺手打信号：有没有纠正 / 夸它 / 嫌它啰嗦 / 顺口提自己
          再兜底回填一次             ← 仍然是纯本地写文件

—— 跟对话无关、到点自己跑的那部分 ——
每分钟一个自检 tick：过了 23:00（或发现昨天该写没写）
且当天流水比上次覆盖的多 →  补写日记 → 蒸馏特质（跨两天才转正）
                          → 顺手记 1~2 条该记的话 → 巩固（合并近重复、太淡的退场）
```

两个容易误会的地方：

- **流水记的是问答对**，不记工具调用的中间过程。工具跑几十次，流水里也只有你一句、它一句。
- **日记不是「你说话才写」**，是到点自检补写；电脑睡一晚、定时器被系统干掉都不会漏。

## 三个子系统

| 系统 | 干什么 | 存在哪 |
| --- | --- | --- |
| 人设 | 地基三段：身份 / 说话方式 / 边界，每轮都注入，可导入导出 | `state.json` 的 `persona` |
| 成长 | 记流水 → 写日记 → 蒸馏出特质（跨两天才转正，按 salience 衰减） | `journal/`、`diary/`、`traits.json` |
| 记忆 | 一句话一条的事实（可检索、会变淡、不删），每晚顺手记几条 | `memory.json` |

## 它是怎么长的

1. **记流水**（每轮，零成本）：每轮结束把「他说了什么 / 我说了什么」加一条正则信号（有没有纠正、有没有夸、有没有嫌啰嗦、有没有顺口提自己），写进 `journal/YYYY-MM-DD.jsonl`。
2. **写日记**（每天 `diaryTime`，默认 23:00）：纯规则拼一篇**第一人称**的日记，落到 `diary/YYYY-MM-DD.md`。
   - 不是一次定时器：每分钟自检一次「过点了没 / 当天流水有没有比日记覆盖的多」，有就补写。电脑睡一晚、定时器被系统干掉都不会漏。
   - 同一天重写是幂等的：特质按「天」计数，补写不会把分数刷上去。
   - 日记是「我」在说话，不是统计报表：不写"聊了 9 轮 / 词频 3 次"。
   - 只写有画面的部分：他纠正我的、他嫌我说话的、他笑了、顺口带过的。一天什么信号都没有，就留一两句他真说过的话当锚。
3. **蒸馏**：从流水里抽出候选认识（`traits.json`）。
   - 每条认识 = **一句抽象判断 + 一个具体瞬间**（`—— 「他原话」`）；没有原话画面的判断不落地，链接 / 命令 / 粘贴的代码一律不当证据。
   - **候选**：今天出现过就算候选，不进系统提示。
   - **生效**：同一类事**跨两天**都出现，才转正 → 只有生效的才注入。
   - 这一条是故意设的门槛：单次口误不该被写进人格。
   - **遗忘**：每条带 `salience`，按闲置天数每天 ×0.93 衰减；低于 `minSalience`（默认 0.15）的不进注入，但档案里还留着。
4. **注入**：每轮拼一段 `<自我记忆>` 进系统提示，四栏（顺序就是人设 → 特质 → 记忆 → 最近/想起来）：
   - 人设地基（身份 / 说话方式 / 边界，永远最前）
   - 我对他的一些印象（长期特质，按 salience 取，超预算丢最不重要的）
   - 我记得的事（一句话一条的事实，按这轮话头检索命中，没命中就按重要度补几条）
   - 最近的事 + 突然想起来（最近三篇日记的锚永远在场；话头命中更早的日记才会捡出来——像人偶尔走神想起旧事）
   这些只影响身份和说话方式，不改变任务、权限、工具约定。

## 记忆怎么算「记得住」

照搬一套双轴强度，不落库、每次实时算：`S = 0.7·exp(-Δt/τ) + 0.3·min(1, ln(1+hit)/ln16)`，τ 按类型给（fact/lesson/rules/soul/user 365 天、project 180、topic 90）。`S ≥ 0.55` 算清晰、`≥ 0.25` 算模糊、`< 0.25` 不再主动注入、`< 0.10` 降成退役（stale，不物理删）。近重复（关键词重叠 + 前 24 字相同）在每晚巩固时合并成一条。


### 说法打架怎么办：先冻住，等他裁决

记忆里最容易出错的不是「记不住」，是「记反了还理直气壮」。所以新记一条时会先跟旧的比一遍：

- 文本一模一样 → 只把旧那条的重要度和命中数抬一下，不新增。
- 疑似同一件事、说法不同（相似度 ≥ 0.55，**或者开头一长段完全一样、只是后面的值换了**——「他的生日是三月五日 / 四月九日」这种）→ 新那条不生效，标成 `pending`，挂在旧条目旁边等裁决。
- 这时候注入里会多一句：「有 N 条说法打架的事我拿不准，先不当作数」。**宁可不记得，也不要记反了还嘴硬。**
- 面板上会出现「有 N 条说法打架，等你定」，三个按钮：用新的（旧的标 `superseded`）/ 留旧的（新的标 `dropped`）/ 两条都留。
- 改一条旧记忆时，旧版本会留在 `history` 里（最多 5 版），不会无声无息被覆盖。

全程**纯本地规则**：不调模型、不联网、不花 token。日志、日记、特质都在本机。

## 注入怎么排队（硬预算）

每轮注入的不是随便几个字符串，而是一块**有硬上限**的自我记忆，按比例切好，塞满就停：

| 块 | 占比 | 内容 |
|---|---|---|
| 上次的交接 | 24% | 上个会话最后在干什么（3 天内的接续卡） |
| 我是什么样的人 | 22% | 长出来的特质（带一句原话证据） |
| 我记得的事 | 28% | 记忆库按当前话头检索出来的条目 |
| 最近的事 | 14% | 最近 3 篇日记的锚 |
| 突然想起来 | 12% | 更早的日记里被话头勾到的 |

预算默认 1200 字（面板可调）。每块算 `min(块上限, 剩余预算)`，剩下不到 20 字就整块丢掉——**宁可少注入，也不让上下文被自己撑爆**。

## 换会话以后，还是原来那条鱼吗

这是被问得最多的一句。实话分两半说：

**留得下来的**（都在本地文件里，换个会话、换个 profile 都在）：人设三段、长出来的特质（带原话证据）、记忆条目、日记、接续卡。

**留不下来的**：这一个会话里当场说过的原话、玩笑的节奏、没被记成特质的语气。换过去它确实会「忘掉刚刚那两小时」。

所以做了**温启动**：新会话的头两轮，注入预算自动放大到 1.7 倍（上限 2000 字），而且最近的事多给一条、突然想起来多给一条——先让它认清自己是谁、之前在做什么，再回落正常预算。聊开之后（问答对 > 2）立刻回正，不会每轮都付这笔钱。

一句话：**换会话不是换鱼，是同一个人的记忆还在，只是刚才那段对话没带上。** 记忆越攒越厚，这个接缝就越不明显；头几天特质还没转正，感觉最薄——这是这套机制的真实短板，我不打算藏。

## 接续卡（会话太长了就交接）

同一个对话聊到 24 组问答、且离上次写卡超过 30 分钟，就会写一张 800 字以内的交接卡：「在做什么 / 卡在哪 / 我最后答的是什么 / 最后两轮 / 接着往下做就行」。

新会话（问答对 ≤ 2）第一轮会把 3 天内最新的那张卡顶到注入最前面，所以开新对话不用从头解释。卡同时留档在 `handoff/<时间>.md`。

## 眼睛

`glm-4v-flash`（智谱免费档）直连，不花 DeepSeek 的钱。看图返回一句描述进上下文，几百 token，比把原图喂给视觉模型便宜。

key 自己找：环境变量 `GLM_API_KEY` / `ZHIPU_API_KEY` → 注册表 `HKCU\Environment` → `$DSH_HOME/.credentials.yaml`。三处都没有就只会说「看不了」，不报错。

## 设置面板

DSH 设置 → 左侧「自己」：

- 总电源：开了还不生效，还要在下面勾具体对话（可以勾多个）
- 在哪些对话里启用：按对话标题勾选，也可手工填会话 id
- 日记时间、特质注入预算
- **人设**三段文本框（身份 / 说话方式 / 边界）+ 保存 / 导出 JSON / 导入 / 恢复默认
- 长出来的特质列表：候选 / 生效 / 退役，可手动加一条、转正、退役、删
- **记忆**：搜索、列表（可删）、手动记一条（选层级）、**说法打架的等你裁决**（用新的 / 留旧的 / 两条都留）
- 日记：选日期看全文、立刻写一篇蒸馏

## 工具（对话里可用）

- `soul_status` —— 看自己现在的状态（人设、特质、记忆条数、日记数、眼睛、交接卡、数据目录、启用了哪些对话）
- `soul_diary` —— 列日记 / 读某一天的全文
- `soul_trait` —— 列出、添加、退休、恢复、删除特质
- `soul_memory` —— 记忆：`list` / `search` / `add`（打架会返回 `conflict`，加 `force` 强制记） / `update` / `drop` / `pending`（看等裁决的） / `resolve`（`keep=new|old|both`）
- `soul_session` —— 启用的对话：`current`（勾这个对话）/ `list` / `add <id>` / `remove <id>`
- `soul_see` —— 用眼睛看一张图：本地路径或 http(s) 链接，可带一句 `question`，返回看到的描述；看不了只回一句原因
- `soul_handoff` —— 接续卡：`read` 读最新的、`write` 按当前流水写一张
- `soul_group_replay` —— 翻群聊前情：只读本地会话日志，把最近 N 分钟「群友说了什么 + 我真发出去的回话」排成剧本（`minutes` 默认 60，最多 240；`limit` 默认 160）。给 QQ 群场景用：群消息走旧桥接没有 rpcId，`dsh_im_group_history` 永远报无权，这个不需要任何 shell 权限

## 数据在哪

```
$DSH_HOME/own-soul/<profileKey>/
├── state.json          # 开关、启用的对话、日记时间、预算、人设三段
├── traits.json         # 长出来的自己
├── memory.json         # 记得的事
├── handoff.json        # 最新接续卡
├── handoff/<时间>.md   # 每张卡的留档
├── journal/YYYY-MM-DD.jsonl
├── diary/YYYY-MM-DD.md
└── snapshots/          # 每次改设置/写日记前的快照，留 30 份
```

改了设置或者觉得长歪了：删 `traits.json` 就回到只有地基的状态；从 `snapshots/` 里挑一份拷回去就能回滚。

## 从 meow-memory 搬过来

```bash
ELECTRON_RUN_AS_NODE=1 "<DeepSeek Harness.exe>" --expose-internals \
  scripts/import-meow.mjs "D:/BigFatFish/.dsh-meow/memory.db" "$DSH_HOME/own-soul/<profileKey>"
```

读 meow 的七张表（soul/user/fact/lesson/rules/project/topic），映射成统一条目，按内容去重后写进 `memory.json`。可以重复跑，不会长出重复条目。

## 边界

- 人设、成长、记忆三件事它都管，装它就不用再装 meow-memory 那类记忆插件（两边同时注入会重复、还会打架）。
- 只管「我是谁、我怎么说话 + 我记得什么」。项目文档、代码检索这类事不归它管。
- 不主动复述日记、不炫设定；注入的只有人设 + 生效特质 + 命中的记忆 + 最近的事。
